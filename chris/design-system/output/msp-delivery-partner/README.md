## Editing and Rebuilding

For simple edits, open the standalone HTML in a text editor. It already contains all required assets.
For repeatable exports, edit two-pager.html and run export-two-pager.cjs with the bundled Node runtime and Playwright/Sharp dependencies. The builder expects the workspace design-system files and local official icon library.

Verification: verification.json contains browser layout checks. pdf-verification.json contains page, content, font, and contact-link checks. PDF-rendered page PNGs were also visually reviewed.
